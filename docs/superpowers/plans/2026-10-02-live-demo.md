# Live Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `DEMO_MODE` that turns a ParishCRM deployment into a safe, public, nightly-reset sandbox with one-click role logins and realistic synthetic parish data.

**Architecture:** One dependency-free helper (`src/lib/demoMode.ts`) is the single source of truth for the flag. Boot-time `envCheck` makes "no outbound secrets" an invariant. `authorize()` gains a `mode: "demo"` branch that only signs into `@demo.invalid` users. Blocked Server Actions/routes call `assertNotDemo()` as their first statement. A pure, deterministic data builder (`scripts/demo/demoData.ts`) feeds a thin writer script (`scripts/demo/seed-demo.ts`) that encrypts PII exactly like the app.

**Tech Stack:** Next.js 16 App Router + Server Actions, NextAuth v5 Credentials, Prisma 7 (`@prisma/adapter-pg`), Jest 30 + Testing Library, tsx scripts.

**Spec:** `docs/superpowers/specs/2026-10-02-live-demo-design.md`

## Global Constraints

- Flag: `DEMO_MODE=true` (exact string). Unset/any other value = demo off, zero behaviour change.
- Reserved demo user domain: `@demo.invalid`. Demo login rejects any other email.
- Demo error string (exact): `Disabled in the live demo`
- Import preview cap in demo mode: `200 * 1024` bytes.
- Banner copy (exact): `Live demo — shared sandbox, resets nightly. Don't enter real data.`
- Forbidden in demo mode (boot fails): `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `RESEND_API_KEY`, `WEBSITE_SYNC_URL`, `WEBSITE_SYNC_SECRET`, `APPLICATIONINSIGHTS_CONNECTION_STRING`, `GITHUB_TOKEN`, and `STRIPE_SECRET_KEY` starting `sk_live_`.
- Public AGPL repo: synthetic data only. Emails `@example.com`; mobiles from the ACMA fictional range `0491 570 006`–`0491 570 159`; invented suburb names.
- Money: integer cents in generator, converted to `"D.CC"` strings for Prisma `Decimal`. Never `parseFloat`/`Number()` on money (semgrep rule).
- Dates: calendar dates at UTC midnight (`Date.UTC(y, m, d)`); `dateOfBirth` plaintext is `YYYY-MM-DD`.
- PII written by the generator goes through `encrypt`/`hmacEmail`/`hmacMobile` from `src/lib/cryptoCore.ts` (not `src/lib/crypto.ts`, which is `server-only`).
- Tests: `npm test -- --testPathPatterns="<pattern>"`. Lint: `npm run lint`. No local `npm run build`.
- Commits: Conventional Commits, end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

```ts
// Live-demo switch. Dependency-free on purpose: imported by envCheck,
// schedulerFlag, auth, Server Actions, and server components alike.
// The public demo (docs/live-demo.md) sets DEMO_MODE=true; every real
// deployment leaves it unset, which must mean zero behaviour change.

export type UserRoleName = "ADMIN" | "PASTOR" | "OFFICE_ADMIN" | "AUDITOR" | "VIEWER" | "EVENT_ORGANISER"

export const DEMO_ERROR = "Disabled in the live demo"
export const DEMO_EMAIL_DOMAIN = "@demo.invalid"
export const DEMO_IMPORT_MAX_BYTES = 200 * 1024

// One-click logins shown on /login. Demo login only ever signs into these
// reserved-domain users, so a real deployment that sets DEMO_MODE by mistake
// (and has no such users) fails closed.
export const DEMO_LOGINS: ReadonlyArray<{ role: UserRoleName; label: string; email: string }> = [
  { role: "ADMIN", label: "Admin", email: `admin${DEMO_EMAIL_DOMAIN}` },
  { role: "PASTOR", label: "Pastor", email: `pastor${DEMO_EMAIL_DOMAIN}` },
  { role: "OFFICE_ADMIN", label: "Office Admin", email: `office${DEMO_EMAIL_DOMAIN}` },
  { role: "AUDITOR", label: "Auditor", email: `auditor${DEMO_EMAIL_DOMAIN}` },
  { role: "VIEWER", label: "Viewer", email: `viewer${DEMO_EMAIL_DOMAIN}` },
  { role: "EVENT_ORGANISER", label: "Event Organiser", email: `organiser${DEMO_EMAIL_DOMAIN}` },
]

export function isDemoMode(env: Record<string, string | undefined> = process.env): boolean {
  return env.DEMO_MODE === "true"
}

export function isDemoEmail(email: string): boolean {
  return email.toLowerCase().endsWith(DEMO_EMAIL_DOMAIN)
}

// First statement of every blocked Server Action / route, before auth():
// the error leaks nothing, and keeping it first makes the guard trivially
// testable and impossible to bypass via an early-return path.
export function assertNotDemo(): { error: string } | null {
  return isDemoMode() ? { error: DEMO_ERROR } : null
}
```

```ts
function mulberry32(seed: number): () => number {
  let a = seed >>> 0
  return () => {
    a = (a + 0x6d2b79f5) >>> 0
    let t = a
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
```

```ts
  const extra = await prisma.family.count({ where: { name: { not: "Sample" } } })
  if (extra > 0) throw new Error(`${extra} families already present — run after a reset (prisma migrate reset + db:seed).`)

  const accounts = new Map((await prisma.account.findMany({ select: { id: true, code: true, name: true } })).map((a) => [a.code, a]))

  }
```

## PR 2 — Demo reset workflow (outline, after PR 1 is released)

Single task. File `.github/workflows/demo-reset.yml`:

```yaml
name: demo-reset
on:
  schedule: [{ cron: "0 17 * * *" }]   # 03:00 AEST / 04:00 AEDT
  workflow_dispatch:
permissions: { contents: read }
concurrency: { group: demo-reset, cancel-in-progress: false }
jobs:
  reset:
    if: github.repository == 'ginutgeorge-Aus/parishcrm'
    runs-on: ubuntu-latest
    timeout-minutes: 15
    env:
      DATABASE_URL: ${{ secrets.DEMO_DATABASE_URL }}
      ENCRYPTION_KEY: ${{ secrets.DEMO_ENCRYPTION_KEY }}
      DEMO_MODE: "true"
      ALLOW_DEMO_SEED: "true"
    steps:
      - id: tag
        env: { GH_TOKEN: "${{ github.token }}" }
        run: echo "tag=$(gh release view --repo "$GITHUB_REPOSITORY" --json tagName -q .tagName)" >> "$GITHUB_OUTPUT"
      - uses: actions/checkout@<pinned-sha>   # pin like the other workflows
        with: { ref: "${{ steps.tag.outputs.tag }}", persist-credentials: false }
      - uses: actions/setup-node@<pinned-sha>
        with: { node-version-file: .nvmrc, cache: npm }
      - run: npm ci
      - run: npx prisma migrate reset --force
      - run: npm run db:seed
      - run: npm run demo:seed
      - name: Redeploy demo
        env: { HOOK: "${{ secrets.RENDER_DEPLOY_HOOK }}" }
        run: curl -fsS -X POST "$HOOK" > /dev/null
```
