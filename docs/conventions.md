# File Conventions

Patterns and gotchas for working in this codebase. Read on demand.

- Server Components by default; `"use client"` only for event handlers/hooks.
- API routes: `src/app/api/[resource]/route.ts` — validate session before mutating.
- `src/components/ui/` — shadcn, don't edit directly. `lucide-react` for icons.
- Business logic: `src/lib/`. Type extensions: `src/types/next-auth.d.ts`.
- **Server + client split**: server page wrapper + `*Client.tsx` for role redirect + client interactivity.
- **Multi-step UI**: orchestrator owns state + renders active step; sub-components props/callbacks only. Shared types in leaf, re-exported. See `BankImportClient.tsx`.
- **URL-param server filtering**: filters in URL query string, client `*Filters.tsx` pushes via `useRouter`, Server Component reads `searchParams` and queries DB. Use for any large list.
- **`React.Fragment` key**: `<React.Fragment key={...}>` — `<>` shorthand rejects `key` prop.
- **Radix Select gotcha**: `<SelectItem value="">` throws — use native `<select>` for optional/clearable selects.
- **Sidebar**: `src/components/layout/Sidebar.tsx` — collapsible sections, active auto-expands, role-visibility per item. Uses inline string comparisons (`role === "ADMIN"`) not `UserRole` enum — client component using `useSession()` returns strings, not enum values.
- **Idle timeout**: `src/components/auth/IdleTimeout.tsx` — warning at 59 min, sign out at 60 min.
- **`lang="en-AU"`** on `<html>` — required for DD/MM/YYYY in Chrome date inputs. Don't change to `lang="en"`.
- **Error boundaries**: `src/app/error.tsx` + `src/app/(dashboard)/error.tsx`, both `"use client"`, expose `reset()`.
- **`next.config.mjs`**: `unpdf`, `pdfjs-dist`, `pdfkit`, `nodemailer`, `@prisma/client`, `bcryptjs`, `@azure/monitor-opentelemetry` in `serverExternalPackages`. `output: 'standalone'`. Security headers on `/(.*)`.
- **TypeScript Set spread**: `Array.from(new Set(...))` — `[...new Set()]` won't compile.
- **FY derivation**: `const fyYear = now.getMonth() >= 6 ? now.getFullYear() : now.getFullYear() - 1`. Range: `gte: new Date(\`${fyYear}-07-01\`), lt: new Date(\`${fyYear+1}-07-01\`)`.
- **Month abbr**: `const MONTH_ABBR = ["JAN","FEB","MAR","APR","MAY","JUN","JUL","AUG","SEP","OCT","NOV","DEC"]` — `toLocaleString` unreliable on `node:alpine`.
- **Tailwind content paths**: `tailwind.config.ts` uses `./src/**/*.{js,ts,jsx,tsx,mdx}` — all source under `src/`. Don't revert to `./app/**` or `./components/**` (those paths empty; Tailwind purges all classes in prod build, stripping all styles).
- **Optimistic inline toggle pattern**: `useState(initialValue)` for local display + `useTransition` to call action + revert on `result?.error`. See `ReconcileToggleButton.tsx` and `DeleteTransactionButton.tsx`. Don't use `useActionState` for these — direct call pattern only.
- **Dashboard Server Component query pattern**: all queries run in one `Promise.all` in `src/app/(dashboard)/page.tsx`. Role-conditional entries use ternary: `canViewAccounting(role) ? prisma.X... : Promise.resolve(fallback)`. Pure-presentational children (`ActivityFeed`, `BirthdayWidget`) receive only what they display — always `select` specific fields, never `include`.

## Source Layout

```
src/
  app/                    # Next.js App Router (route groups below)
    (auth)/               # /login — unauthenticated
    (dashboard)/          # / families/ people/ users/ accounting/ events/
    (public)/             # /e/[slug], /family/update/[token] — no auth
    (print)/              # P&L, family directory, event regs, petty-cash session
    api/                  # API routes
  components/
    accounting/ auth/ dashboard/ events/ families/ import/
    layout/               # Sidebar, nav
    people/ petty-cash/ public-event/ settings/ users/
    ui/                   # shadcn — do not edit
  lib/
    actions/              # Server actions
    generated/prisma/     # Prisma client (generated by postinstall, gitignored — not in node_modules)
    reports/              # plHelpers.ts — pure P&L calculation helpers
  types/                  # next-auth.d.ts and other type extensions
  instrumentation.ts      # Next.js register() — optional App Insights (Node runtime only)
```

**`src/lib/` naming**: camelCase throughout (`pettyCashLedger.ts`, `bankMatch.ts`, `roleGuard.ts`, `cryptoCore.ts`, …). The former kebab-case outliers (`role-guard`, `accounting-lock`, `website-sync`, `env-check`, `settings-constants`, `telemetry-redact`, `crypto-core`) were renamed to camelCase in one atomic pass. New lib files follow camelCase — no exceptions.
